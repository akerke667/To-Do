TaskManager — тапсырмаларды басқару жүйесі
Жоба туралы

TaskManager — PHP және MySQL технологияларымен жасалатын тапсырмаларды басқаруға арналған веб-қосымша.

Жобаның мақсаты

Пайдаланушыларға жеке тапсырмаларын құруға, өңдеуге, жоюға және олардың орындалу барысын бақылауға мүмкіндік беру.

Дерекқор

Жоба үш негізгі кестеден тұрады: users, tasks, categories.

Орнату
XAMPP бағдарламасын орнатыңыз.
Apache және MySQL серверлерін іске қосыңыз.
Жоба файлдарын htdocs/task-manager қалтасына орналастырыңыз.
phpMyAdmin арқылы task_manager дерекқорын құрыңыз.
database/task_manager.sql файлын импорттаңыз.
config/database.php файлына дерекқор қосылымының параметрлерін енгізіңіз.
Браузерде http://localhost/task-manager/ мекенжайын ашыңыз.
